# Release Notes - Phiên bản v1.0.0

## Ngày phát hành

05/11/2026

## Chức năng mới

- Ra mắt trang web CV/portfolio cá nhân bằng HTML5 và CSS3.
- Thêm phần giới thiệu Hero với tên, vai trò, mô tả và ảnh đại diện.
- Thêm thanh điều hướng sticky và nút cuộn trở về đầu trang.
- Thêm danh sách kỹ năng và danh sách dự án tiêu biểu dạng card.
- Thêm phần liên hệ qua Email, GitHub và LinkedIn.
- Hỗ trợ bố cục responsive trên điện thoại, máy tính bảng và máy tính để bàn bằng Flexbox, CSS Grid và Media Queries.
- Hỗ trợ cuộn mượt đến từng phần nội dung và tùy chọn giảm chuyển động theo thiết lập của trình duyệt.
- Thêm tài liệu README hướng dẫn cấu hình, cài đặt và chạy thử dự án.

## Lỗi đã sửa

- Thay đổi tên hiển thị trên trang chủ.
- Khắc phục thuộc tính và cách hiển thị ảnh để trang hiển thị tốt hơn trên giao diện responsive.
- Khắc phục tràn bố cục nhỏ tại vùng ảnh bằng cách điều chỉnh kích thước responsive.

## Hạn chế còn tồn tại

- Dự án là trang web tĩnh, chưa có backend, cơ sở dữ liệu hoặc biểu mẫu liên hệ lưu trữ dữ liệu.
- Chưa sử dụng framework JavaScript và chưa có chức năng tìm kiếm, đăng nhập hoặc quản lý nội dung động.
- Chưa có bộ kiểm thử tự động cho giao diện và tương tác.
- Một số liên kết hoặc nội dung dự án có thể cần được cập nhật bằng dữ liệu cá nhân thực tế trước khi triển khai công khai.
